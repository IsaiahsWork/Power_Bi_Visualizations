Home Loan Analysis Dashboard (Power BI)

Overview

This project features a fully interactive Power BI dashboard built using real government CFPB data. It aims to answer key questions regarding home loan data, such as:

"What are the average spread rates by state?"

"Which institutions provide the best loan rates overall (e.g., Freddie Mac vs. Private Institutions)?"

"Who has issued the most loans? (Private banks, Fannie Mae, etc.)"

"What is the average Debt-to-Income Ratio by state?"

Features

Data Visualization: Interactive charts and tables to explore loan data across states, institutions, and other variables.

Key Performance Indicators (KPIs): Metrics such as loan spread rates, Debt-to-Income Ratios, and loan distribution by institution.

Data Transformation: Cleaned and transformed using DAX to ensure data accuracy and provide meaningful calculations for deeper insights.

Key Insights

Analyzed loan rates and institutions across the U.S., identifying patterns and trends.

Visualized how loan rates and financial health (DTI ratios) vary by state and institution.

Provided a comprehensive view of loan distribution to help users understand the mortgage landscape.

Technical Details

Data Source: Real government CFPB dataset (over 5 million entries)

Tool: Power BI

Data Transformation: DAX for data cleaning and calculation of KPIs
